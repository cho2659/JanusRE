1-P. 함수 검색창에 thread 표시 안됨
1-S. 함수 검색창에 thread 포함하여 표시
2-P. 함수 검색창에 중복 호출 함수 '(3)' 형태로 표시 
2-S. 함수 검색창에 호출 시간 순서대로 중복 이더라도 모두 따로 표시. 단, 중복 함수는 total 호출 수를 표시
3-P. 사용자가 그래프 이동하고 다른 스레드 탭 방문후 혹은 더블 클릭 후면 다시 하나로 뭉침 
4-P. 그래프의 제약 조건인 함수 노드별 위상(어느 노드보다 오른쪽에 있는지랑 어느 노드보다 아래에 있는지 등) 이동 제약이 없음 
5-P. 그래프를 접거나 펼칠 수 없고 기본적으로 모두 펼쳐져있는 상태이며 여전히 노드의 초기 위치는 원점으로 동일함.
5-S. 그래프는 기본적으로 접혀있어야하고 예외적으로 메인 스레드는 방금 전 명령 입력과 같은 규칙이 적용되어야함 이는 추후 ui 속도를 위한 것임
6-P. 같은 스레드에서 여러번 중복으로 호출된 함수는 그래프에서 하나의 노드로만 나타나 있음
6-S. 같은 함수라도 개별적 노드로 처리해야함 이는 하위 호출 함수 및 부모 함수 파악을 위함이고 오히려 이로써 더 깔끔한 그래프를 만들 수 있음
7-P. 노드에서 하위 호출 함수 화살표 시작점의 위아래 위치 및 간격이 그래프 노드 이동으로 변경됨
7-S. 먼저 호출하는 함수는 위에 화살표 시작점을 두고 화살표 시작점 간격은 동일하며 화살표 시작점 왼쪽에 해당 호출 함수 명이 있어야함
8-P. 스크립트를 실행한 창(예. main.exe)을 제외하고 프로젝트에서 열린 다른 창(예. sub.dll)에서는 goto가 적용되지 않음

정의:
접는다: 부모 노드에서 하위 함수의 화살표 아이콘을 클릭해 접음
펼친다: 부모 노드에서 하위 함수의 화살표 아이콘을 클릭해 펼침
